# GestionEvent

Application de gestion d'événements développée dans le cadre d'un projet de groupe.

##  Structure du projet

* `event-frontend/` — interface utilisateur de l'application
* `event-backend/` — partie serveur et logique backend

##  Installation

### Backend

```bash
cd event-backend
npm install
npm run dev
```

### Frontend

```bash
cd event-frontend
npm install
npm run dev
```

##  Technologies

* Frontend : Vite / TypeScript
* Backend : Node.js

##  Projet

Projet réalisé en groupe.

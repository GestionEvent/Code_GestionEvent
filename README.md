# Application de Gestion d'Événements — Front-End (Version Alpha)

Bienvenue dans le dépôt du module Front-End de l'application **Gestion d'Événements**. Ce projet est développé en JavaScript / React et constitue l'interface utilisateur servant à la consultation, la création et la gestion d'événements.

---

## Technologies & Outils

- **Framework / Bibliothèque** : React.js (JSX)
- **Langage** : JavaScript , HTML5, CSS3
- **Gestionnaire de paquets** : npm
- **Gestion de version** : Git & GitHub
- **IDE recommandé** : Visual Studio Code

---
